# 【專案代號】圖庫下載接入說明

> 新專案建立時**先填本檔**，再貼給 Cursor／同事。  
> AI 或人員依此知道：共用套件在哪、參考哪個已跑通的專案、要複製哪些檔。

---

## 一、先填這張表（必填）

| 項目 | 填寫 |
|------|------|
| **本專案代號** | 【例：CAI12A】 |
| **本專案根目錄** | `D:/GITHUB_2/【專案資料夾名】` |
| **共用 stock-picker** | `D:/GITHUB_2/圖庫下載說明` |
| **參考專案（已接好）** | `D:/GITHUB_2/UIO16A 加拉巴哥群島 厄瓜多 哥倫比亞雙城 咖啡風情 16日` |
| **素材輸出資料夾** | `images/【專案代號】-shutter` |
| **官網 CDN（上線後）** | `https://www.tcawg.com/data/images/YYYYMM/【專案代號】/` |
| **NAS 主機** | `\\192.168.3.3\【行程總彙】`（主）、`\\192.168.3.11\public`（第二台 QNAP） |

## 二、給 Cursor 的指令（複製貼上）

把下面整段貼到新專案對話，並把【】內改成實際值：

```
請幫這個新行程專案接入 tcawg-stock-picker 圖庫下載機制。

【專案代號】：CAI12A
【本專案根目錄】：D:/GITHUB_2/...
【共用套件】：D:/GITHUB_2/圖庫下載說明
【參考專案】：D:/GITHUB_2/UIO16A 加拉巴哥群島 厄瓜多 哥倫比亞雙城 咖啡風情 16日

請依參考專案複製薄包裝腳本與設定，不要複製整包 tcawg-stock-picker，也不要複製參考專案的 image-slots 內容。

要做的事：
1. 建立 stock-picker.config.json（改 targetRoot 為 images/【專案代號】-shutter）
2. 從 D:/GITHUB_2/圖庫下載說明/templates/image-slots.example.json 建立 scripts/image-slots.json 骨架
3. 從參考專案複製：scripts/find-images.js、fill-slots.js、sync-slot-images.js、setup-env.ps1、scripts/lib/stock-picker-path.cjs
4. scripts/package.json 加入 "tcawg-stock-picker": "file:../../圖庫下載說明" 並 npm install（勿複製 UIO16A 整包 package.json）
5. 建立 public/images/{pexels,unsplash,shutterstock}/，各放空 credits.json（格式 []）
6. 複製 D:/GITHUB_2/圖庫下載說明/templates/圖庫下載.cursor-rule.mdc → .cursor/rules/圖庫下載.mdc
7. 執行 setup-env.ps1 與 node scripts/find-images.js --check-keys 確認

詳細流程見：D:/GITHUB_2/圖庫下載說明/templates/新專案流程清單.md
```

## 三、從參考專案複製什麼（清單）

### 必複製（薄包裝，幾乎不用改）

| 來源（UIO16A） | 目的 |
|----------------|------|
| `scripts/find-images.js` | 互動搜圖 |
| `scripts/fill-slots.js` | 批次補圖 |
| `scripts/sync-slot-images.js` | archive → 素材同步 |
| `scripts/setup-env.ps1` | 轉呼叫 tcawg-stock-picker 建 .env |
| `scripts/lib/stock-picker-path.cjs` | sstk 腳本找 bin 路徑 |
| `scripts/sstk-search.js`、`sstk-license.js` | 可選 |

### 從範本新建（依本專案改內容）

| 範本（`D:/GITHUB_2/圖庫下載說明/templates/`） | 目的 |
|---------------------------------------|------|
| `stock-picker.config.example.json` → 根目錄 `stock-picker.config.json` | 路徑設定 |
| `image-slots.example.json` → `scripts/image-slots.json` | **每張圖 slot，依 HTML 重寫** |
| `圖庫下載.cursor-rule.mdc` → `.cursor/rules/圖庫下載.mdc` | AI 觸發「依照圖庫下載說明」 |

### 不要複製

- `圖庫下載說明/` 整包（共用一份即可）
- 參考專案的 `scripts/image-slots.json`（行程不同）
- 參考專案的 `images/UIO16A-shutter/` 圖檔
- `.env`（用 setup-env 重新產生）

## 四、接好後驗證

在**本專案根目錄**：

```powershell
cd scripts
npm install
cd ..
powershell -File scripts/setup-env.ps1
node scripts/find-images.js --check-keys
node scripts/fill-slots.js --all --free-only
```

預期：
- check-keys 顯示 PEXELS / UNSPLASH / SHUTTERSTOCK 狀態
- fill 後 `images/【專案代號】-shutter/` 有檔案
- `public/images/*/credits.json` 有紀錄

---

## 五、路徑不在 GITHUB_2 同層時

改 `scripts/package.json` 的 `file:` 為實際相對或絕對路徑，例如：

```json
"tcawg-stock-picker": "file:D:/GITHUB_2/圖庫下載說明"
```

或在任何目錄執行時加 `--project`：

```powershell
node D:/GITHUB_2/圖庫下載說明/bin/stock-fill.js --project "D:/path/to/CAI12A" --all --free-only
```

## 六、Cursor 規則

**必備（觸發 AI 執行）**：複製 `templates/圖庫下載.cursor-rule.mdc` → `.cursor/rules/圖庫下載.mdc`。  
之後對 AI 說「依照圖庫下載說明」即可。

**進階可選（依 glob 自動提示）**：複製 `templates/cursor-rule-stock-picker.mdc.example` → `.cursor/rules/stock-image-search.mdc`，並把 frontmatter 裡的 `referenceProject`、`stockPickerRoot` 改成實際路徑。  
開啟 `scripts/image-slots.json` 或搜圖腳本時，AI 會自動帶入共用套件路徑。可與 `圖庫下載.mdc` 並存。
