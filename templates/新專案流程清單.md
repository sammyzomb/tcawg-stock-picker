## 三、stock-picker — 內文素材圖

### 整批（建議先做）

```bash
cd 【專案根目錄】

# 免費來源試跑
node scripts/fill-slots.js --all --free-only

# 滿意後可含 Shutterstock（會扣張數）
node scripts/fill-slots.js --all --confirm-license
```

- [ ] 檢查 `images/【專案代號】-shutter/` 檔案齊全

```bash
node scripts/find-images.js --slot hero
node scripts/fill-slots.js --slot spot-xxx
node scripts/fill-slots.js --weak --free-only
```

```bash

```
